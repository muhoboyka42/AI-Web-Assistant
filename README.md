# 🤖 AI Web Assistant
**Веб-приложение на Flask для ведения диалога с ИИ-ассистентом с сохранением истории диалога.

---

## 🚀 Ключевые особенности (Features)

*  Быстрые ответы ИИ за счет интеграции с Groq API.

* Сохранение контекста и истории диалога в базе данных SQLite.

* Сессионная уникальность: Каждый пользователь получает уникальный ID, что позволяет изолировать историю диалогов.

* Управление контекстом: Возможность мгновенной очистки истории переписки в один клик.

---

## 🎮 Функционал (Functionality)

* Доступ через удобный веб-интерфейс в браузере.

* Поддержка непрерывного диалога с учетом предыдущих сообщений (контекста).

* Автоматическая инициализация системного промта при старте нового диалога.

🏁 Принцип работы: При первом входе пользователю присваивается уникальный UUID. Каждое отправленное сообщение сохраняется в базе данных, после чего передается модели Groq вместе со всей предыдущей историей. Ответ ИИ автоматически отображается в окне чата и сохраняется в БД.

## ⚙️ Установка и Запуск (Installation)

* Клонируйте репозиторий.

* Установите зависимости:

```Bash
pip install flask openai
```
* 🔑 Настройте API Key:
**Замените значение api_key в коде на ваш ключ от Groq API.**

* ▶️ Запустите сервер:

```Bash
python app.py
```

* Откройте в браузере:
**Перейдите по адресу**  [http://127.0.0.1:5000/](http://127.0.0.1:5000/)

## 💾 Схема базы данных (Database Schema) 
**messages**

| Поле | Тип | Описание |
| :--- | :---: | ---: |
| id | INTEGER | Первичный ключ |
| user_ID | INTEGER | Уникальный идентификатор сессии пользователя (UUID) |
| role | TEXT | Отправитель |
| countent | TEXT | Текст сообщения |
